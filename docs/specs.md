# Технические характеристики

**Модель:** `FlexScreen FS-1`

Флагманский гибкий дисплей, спроектированный специально для удобной съемки контента в кафе и ресторанах.

## Основные параметры

| Характеристика | Значение |
| :--- | :--- |
| **Диагональ экрана** | 27" (68,6 см) |
| **Максимальное разрешение** | 4K UHD (3840×2160) с антибликовым покрытием |
| **Встроенная камера** | 1080p, 60 FPS с мгновенным автофокусом |
| **Гибкий корпус** | Изгиб до 180° с надежной фиксацией формы (композитный сплав) |
| **Вес устройства** | 1,8 кг |
| **Интерфейсы и связь** | USB-C, HDMI, Wi-Fi 6, Bluetooth 5.2 |
